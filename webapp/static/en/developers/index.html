The daily Hukamnama, as a free API

Each day's Hukamnama from Sri Harmandir Sahib, Amritsar, as JSON: every line verbatim from Sri Guru Granth Sahib Ji, cited by Ang. Free, with no key and no account.

Quick start

Ask for today's Hukamnama. There is nothing to sign up for, and any website or app may call it, from a server or straight from a browser.

curl https://api.gurbanisoul.com/v1/hukamnama/today

“Today” is the date in Amritsar (UTC+05:30), wherever the request comes from. The Hukamnama usually appears after about 05:30 in the morning there. Until then the answer says "status": "pending" and names the latest published date in latest.

Endpoints

https://api.gurbanisoul.com

GET /v1/hukamnama/today
The Hukamnama for the current date in Amritsar, or a pending answer before it is published.
GET /v1/hukamnama/YYYY-MM-DD
One day, by its Amritsar date. The archive begins on 2026-11-01.
GET /v1/hukamnama?limit=7
The latest published days, newest first: from 1 to 30 of them, 7 when limit is left out. Add include=lines to get every line of each day.
GET /v1/hukamnama/index
Every published day, newest first, with its date, Ang and hash and without the text. For an archive or a sitemap.
GET /v1/status
Whether today's Hukamnama is published yet, and the latest published date.

amritsar_date
The day this Hukamnama belongs to, in Amritsar. Show this date, not your visitor's.
status
published or pending. A pending answer has no lines.
ang, ang_end
The Ang the shabad opens on and the Ang it ends on.
citation
The citation to show with the text.
lines
Every line, in order. gurmukhi is the line, verbatim. translit is a rule-based transliteration. is_heading marks a heading and is_rahao the Rahao line.
author, raag
The author and the raag. When a day's lines are by more than one author, as in a Vaar, the day's author is null and each line carries its own.
range_sha256, scripture_sha256
range_sha256 proves the lines, as shown below. scripture_sha256 names the edition of the text they were read from.
published_at
When the day was published here, in UTC.
lines[].en, translation
An English translation by Dr. Sant Singh Khalsa, where it is included. It is a separate, labelled layer: never present it as the Gurbani.

Check the text yourself

Join the gurmukhi of every line with a newline, take the SHA-256 of the UTF-8 bytes, and compare it with range_sha256. If they differ, show nothing: late is better than wrong.

const res = await fetch("https://api.gurbanisoul.com/v1/hukamnama/today");
const day = await res.json();

if (day.status === "published") {
  const text = day.lines.map((line) => line.gurmukhi).join("\n");
  const bytes = new TextEncoder().encode(text);
  const digest = await crypto.subtle.digest("SHA-256", bytes);
  const hex = [...new Uint8Array(digest)]
    .map((b) => b.toString(16).padStart(2, "0"))
    .join("");
  if (hex !== day.range_sha256) throw new Error("lines do not match range_sha256");
}

Before a day is published here, its lines are read from the same text as the Knowledge Base and proved against this hash. SGPC's page is used only to find the shabad; no character is taken from it.

If a line ever looks wrong, tell us.

Showing the Hukamnama

  • Show the Gurmukhi exactly as it arrives. Do not correct, shorten, re-space or reorder it.
  • Show the whole shabad. Where there is no room for it, link to the day's page (url) instead of cutting it.
  • Name it “Hukamnama · Sri Harmandir Sahib”, give its Amritsar date, and show the citation.
  • Call it “today's” only while its date is still the date in Amritsar.
  • Keep the transliteration and any translation apart from the Gurmukhi, each under its own label.
  • Do not call it official. SGPC publishes the Hukamnama; this API finds the shabad by Ang and serves its text from Sri Guru Granth Sahib Ji.

Credit

Wherever you show the Hukamnama, credit it with a link to the day's page:

<a href="https://gurbanisoul.com/en/hukamnama/2026-11-11">Hukamnama · Sri Harmandir Sahib, via Gurbani Soul</a>

Each record carries these words and the link in attribution. Gurbani Soul is not affiliated with SGPC.

Embed it without code

For a Gurdwara's website or a blog: paste this where the Hukamnama should appear. It runs no script and sets no cookie.

<iframe src="https://gurbanisoul.com/embed/hukamnama?lang=en&amp;theme=auto"
        title="Hukamnama · Sri Harmandir Sahib" loading="lazy"
        style="width:100%;max-width:640px;height:520px;border:0"></iframe>

lang can be en, pa, fr, and theme can be auto, light, dark.

Reliability and limits

  • The API is run with care but without a guarantee. When a day cannot be proved it is held back: late rather than wrong.
  • Answers are cached, today's for about a minute and past days for a day. Send If-None-Match with the ETag you hold and an unchanged answer costs nothing.
  • Once a minute is as often as anyone needs to ask. Too many requests are answered with 429 and a Retry-After header.
  • Errors are JSON with error, code and request_id.
  • Version 1 only grows. Fields may be added; none is renamed or removed without twelve months' notice.

Terms

  • The API is free to use. There is no key, no account and no charge.
  • Credit the Hukamnama as shown above, with the link.
  • Do not alter the Gurmukhi, and do not present it as official or as coming from SGPC.
  • The API is provided as it is, without warranty. Use that harms the service may be limited or blocked.
