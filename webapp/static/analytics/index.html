Insights

Patterns across the whole Granth — which themes appear together, how each author writes, and how the Banis unfold. These are observations, never judgements — nothing here ranks or rates the scripture. Every view is computed offline from the corpus's verified themes and the English translation.
Theme Co-occurrence Network
Which themes tend to appear in the same hymns. Each circle is a theme — bigger means more verses carry it; a line joins two themes that recur together more than coincidence would explain, and a thicker, brighter line means a stronger bond. Drag a circle, pinch (or Ctrl/⌘ + scroll) to zoom, or click a theme to see its verses. The web opens on the strongest links — drag min PPMI down to 0 to reveal every bond, or up to focus.Method · link strength is PPMI, which corrects for how common each theme is on its own.
Author Theme Fingerprint
Every author has a signature — the themes they reach for more than anyone else. The further a point sits from the centre, the more this author leans into that theme versus the Granth's average (1.0 = the Granth average; the ring labels show the exact ×-multiple, e.g. 2.0× = twice as often). Add a second author to compare two voices.Method · "lift" = the author's rate for a theme ÷ the corpus-wide rate, measured on the English translation.
Cross-Contributor Resonance
Which voices echo each other in meaning. For every verse we find its closest matches in meaning; when those belong to a different author, the two "resonate". A thicker ribbon means two voices keep landing on the same ideas far more than their size alone would predict — the deep kinship among the Gurus, the Bhagats, and across traditions. Hover a ribbon to see it both ways.Method · from each verse's nearest neighbours in meaning; ribbon width is lift over the overlap expected from corpus share.

Raag Theme-Progression
How a raag's themes rise and fall as you read it start to finish. Going left → right across the Angs, each coloured band is a theme — the thicker it is at any point, the more those verses dwell on it (the emotional arc of the raag's Bani). Hover a band to follow one theme.Method · band height = how densely that theme is tagged across each slice of the raag, in reading order.
Vaar Anatomy
A Vaar is a ballad built like a ladder: numbered pauri rungs, each introduced by short saloks (couplets). Strikingly, the saloks are often by a different Guru than the pauris — the editorial craft of how the Granth was assembled, shown here in reading order. Tap any unit to open it in the Reader.★ cross-voice = a salok by a different Guru than the pauris.
