ਪਾਠ ਆਪ ਪਰਖੋ

ਹਰ ਪੰਕਤੀ ਦਾ gurmukhi ਨਵੀਂ ਲਾਈਨ (newline) ਨਾਲ ਜੋੜੋ, UTF-8 ਬਾਈਟਾਂ ਦਾ SHA-256 ਕੱਢੋ, ਅਤੇ range_sha256 ਨਾਲ ਮਿਲਾਓ। ਜੇ ਦੋਵੇਂ ਨਾ ਮਿਲਣ ਤਾਂ ਕੁਝ ਨਾ ਦਿਖਾਓ: ਗ਼ਲਤ ਨਾਲੋਂ ਦੇਰ ਚੰਗੀ।

const res = await fetch("https://api.gurbanisoul.com/v1/hukamnama/today");
const day = await res.json();

if (day.status === "published") {
  const text = day.lines.map((line) => line.gurmukhi).join("\n");
  const bytes = new TextEncoder().encode(text);
  const digest = await crypto.subtle.digest("SHA-256", bytes);
  const hex = [...new Uint8Array(digest)]
    .map((b) => b.toString(16).padStart(2, "0"))
    .join("");
  if (hex !== day.range_sha256) throw new Error("lines do not match range_sha256");
}

ਹੁਕਮਨਾਮਾ ਦਿਖਾਉਣ ਬਾਰੇ

  • ਗੁਰਮੁਖੀ ਉਵੇਂ ਹੀ ਦਿਖਾਓ ਜਿਵੇਂ ਮਿਲਦੀ ਹੈ। ਇਸ ਨੂੰ ਨਾ ਸੋਧੋ, ਨਾ ਛੋਟਾ ਕਰੋ, ਨਾ ਇਸ ਦੀਆਂ ਵਿੱਥਾਂ ਜਾਂ ਤਰਤੀਬ ਬਦਲੋ।
  • ਪੂਰਾ ਸ਼ਬਦ ਦਿਖਾਓ। ਜਿੱਥੇ ਥਾਂ ਨਾ ਹੋਵੇ, ਉੱਥੇ ਇਸ ਨੂੰ ਕੱਟਣ ਦੀ ਥਾਂ ਉਸ ਦਿਨ ਦੇ ਪੰਨੇ (url) ਦਾ ਲਿੰਕ ਦਿਓ।
  • ਇਸ ਦਾ ਨਾਂ “ਹੁਕਮਨਾਮਾ · ਸ੍ਰੀ ਹਰਿਮੰਦਰ ਸਾਹਿਬ” ਲਿਖੋ, ਅੰਮ੍ਰਿਤਸਰ ਦੀ ਤਾਰੀਖ਼ ਦਿਓ ਅਤੇ ਹਵਾਲਾ ਦਿਖਾਓ।
  • ਇਸ ਨੂੰ “ਅੱਜ ਦਾ” ਸਿਰਫ਼ ਉਦੋਂ ਤਕ ਕਹੋ ਜਦੋਂ ਤਕ ਇਸ ਦੀ ਤਾਰੀਖ਼ ਅੰਮ੍ਰਿਤਸਰ ਦੀ ਤਾਰੀਖ਼ ਹੈ।
  • ਲਿਪੀਅੰਤਰ ਅਤੇ ਕੋਈ ਵੀ ਅਨੁਵਾਦ ਗੁਰਮੁਖੀ ਤੋਂ ਵੱਖ ਰੱਖੋ, ਹਰ ਇਕ ਆਪਣੇ ਨਾਂ ਹੇਠ।
  • ਇਸ ਨੂੰ ਅਧਿਕਾਰਤ ਨਾ ਕਹੋ। ਹੁਕਮਨਾਮਾ SGPC ਪ੍ਰਕਾਸ਼ਿਤ ਕਰਦੀ ਹੈ; ਇਹ API ਅੰਗ ਅਨੁਸਾਰ ਸ਼ਬਦ ਲੱਭਦਾ ਹੈ ਅਤੇ ਉਸ ਦਾ ਪਾਠ ਸ੍ਰੀ ਗੁਰੂ ਗ੍ਰੰਥ ਸਾਹਿਬ ਜੀ ਵਿੱਚੋਂ ਦਿੰਦਾ ਹੈ।

  • API ਧਿਆਨ ਨਾਲ ਚਲਾਇਆ ਜਾਂਦਾ ਹੈ, ਪਰ ਕੋਈ ਗਾਰੰਟੀ ਨਹੀਂ ਹੈ। ਜਿਸ ਦਿਨ ਦੀ ਤਸਦੀਕ ਨਾ ਹੋ ਸਕੇ ਉਹ ਰੋਕ ਲਿਆ ਜਾਂਦਾ ਹੈ: ਗ਼ਲਤ ਨਾਲੋਂ ਦੇਰ ਚੰਗੀ।
  • ਉੱਤਰ ਕੈਸ਼ ਹੁੰਦੇ ਹਨ: ਅੱਜ ਦਾ ਲਗਭਗ ਇਕ ਮਿੰਟ ਲਈ ਅਤੇ ਪਿਛਲੇ ਦਿਨਾਂ ਦੇ ਇਕ ਦਿਨ ਲਈ। ਆਪਣੇ ਕੋਲ ਪਏ ETag ਨਾਲ If-None-Match ਭੇਜੋ ਤਾਂ ਨਾ ਬਦਲਿਆ ਉੱਤਰ ਦੁਬਾਰਾ ਡਾਊਨਲੋਡ ਨਹੀਂ ਹੁੰਦਾ।
  • ਮਿੰਟ ਵਿਚ ਇਕ ਵਾਰ ਤੋਂ ਵੱਧ ਪੁੱਛਣ ਦੀ ਕਿਸੇ ਨੂੰ ਲੋੜ ਨਹੀਂ। ਬਹੁਤ ਜ਼ਿਆਦਾ ਬੇਨਤੀਆਂ ਦਾ ਉੱਤਰ 429 ਅਤੇ Retry-After ਹੈਡਰ ਨਾਲ ਮਿਲਦਾ ਹੈ।
  • ਗ਼ਲਤੀਆਂ JSON ਵਿਚ ਆਉਂਦੀਆਂ ਹਨ: error, code ਅਤੇ request_id।
  • ਵਰਜਨ 1 ਵਿਚ ਸਿਰਫ਼ ਵਾਧਾ ਹੁੰਦਾ ਹੈ। ਨਵੇਂ ਖੇਤਰ ਜੁੜ ਸਕਦੇ ਹਨ; ਬਾਰਾਂ ਮਹੀਨਿਆਂ ਦੇ ਨੋਟਿਸ ਤੋਂ ਬਿਨਾਂ ਕੋਈ ਖੇਤਰ ਨਾ ਬਦਲਿਆ ਜਾਂਦਾ ਹੈ ਨਾ ਹਟਾਇਆ।

ਸ਼ਰਤਾਂ

  • API ਦੀ ਵਰਤੋਂ ਮੁਫ਼ਤ ਹੈ। ਨਾ ਕੋਈ ਕੁੰਜੀ, ਨਾ ਖਾਤਾ, ਨਾ ਕੋਈ ਫ਼ੀਸ।
  • ਹੁਕਮਨਾਮੇ ਦੇ ਸ੍ਰੋਤ ਦਾ ਜ਼ਿਕਰ ਉੱਪਰ ਦੱਸੇ ਅਨੁਸਾਰ, ਲਿੰਕ ਸਮੇਤ ਕਰੋ।
  • ਗੁਰਮੁਖੀ ਨੂੰ ਨਾ ਬਦਲੋ, ਅਤੇ ਇਸ ਨੂੰ ਅਧਿਕਾਰਤ ਜਾਂ SGPC ਵੱਲੋਂ ਆਇਆ ਨਾ ਦੱਸੋ।
  • API ਜਿਵੇਂ ਹੈ ਉਵੇਂ ਹੀ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ, ਬਿਨਾਂ ਕਿਸੇ ਵਾਰੰਟੀ ਦੇ। ਸੇਵਾ ਨੂੰ ਨੁਕਸਾਨ ਪਹੁੰਚਾਉਣ ਵਾਲੀ ਵਰਤੋਂ ਸੀਮਿਤ ਜਾਂ ਬੰਦ ਕੀਤੀ ਜਾ ਸਕਦੀ ਹੈ।

ਕੋਈ ਸਵਾਲ ਹੈ, ਜਾਂ ਕਿਸੇ ਗੁਰਦੁਆਰੇ ਲਈ ਕੁਝ ਬਣਾ ਰਹੇ ਹੋ? support@gurbanisoul.com ’ਤੇ ਲਿਖੋ।
